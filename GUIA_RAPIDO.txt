📊 ESTRUTURA DAS 4 BASES CRIADAS
================================================================================

1. BASE DE DISTÂNCIAS
   Arquivo: base_distancias_amcs_nordeste_semmar.csv
   Linhas: ~730 AMCs
   Colunas: 1 + 1 sintética + ~77 reais cronológicas
   
   Principais variáveis:
   • code_amc: Identificador
   • dist_rail_sintetica_km: Distância (km) até rede sintética
   • dist_rail_real_YYYY: Distância (km) até rede real no ano YYYY

2. BASE DE DUMMY
   Arquivo: base_dummy_atendimento_simples.csv
   Linhas: ~730 AMCs
   Colunas: 1 + 1 sintética + ~77 reais cronológicas
   
   Principais variáveis:
   • code_amc: Identificador
   • dummy_atendida_sintetica: 1/0 se atendida (sintética)
   • dummy_atendida_real_YYYY: 1/0 se atendida (real, até YYYY)
   
   Nota: Limiar padrão = 25 km (ajuste em 2_Criar_Base_Dummy_Atendimento.R)

3. BASE DE DENSIDADE
   Arquivo: base_densidade_simplificada.csv
   Linhas: ~730 AMCs
   Colunas: 1 + 1 sintética + ~77 reais cronológicas
   
   Principais variáveis:
   • code_amc: Identificador
   • densidade_sintetica: km de ferrovia por 1000 km²
   • densidade_real_YYYY: km de ferrovia (até YYYY) por 1000 km²

4. BASE INTEGRADA (USE ESTA!)
   Arquivo: base_completa_integrada.csv ou .rds
   Linhas: ~730 AMCs
   Colunas: ~1.700 (inclui tudo acima)
   
   Todas as variáveis em uma única tabela
   Pronta para análises econométricas

================================================================================
📈 EXEMPLOS DE ANÁLISE
================================================================================

1. CARREGAR E INSPECIONAR:
   base <- read.csv("base_completa_integrada.csv")
   dim(base)          # Dimensões
   head(base[, 1:10]) # Primeiras linhas e colunas
   summary(base[, c("dist_rail_sintetica_km", "dist_rail_real_2003")])

2. ANÁLISE IV SIMPLES:
   library(fixest)
   
   # Primeiro estágio
   fs <- lm(dist_rail_real_2003 ~ dist_rail_sintetica_km, data = base)
   summary(fs)
   
   # Segundo estágio (estimado manualmente)
   base$fitted_dist <- predict(fs)
   ss <- lm(log(y_2003) ~ fitted_dist, data = base)
   summary(ss)

3. DENSIDADE COMO VARIÁVEL:
   lm(log(y_2003) ~ densidade_real_2003, data = base)

4. DUMMY COMO TRATAMENTO:
   lm(log(y_2003) ~ dummy_atendida_real_2003, data = base)

5. EVOLUÇÃO AO LONGO DO TEMPO:
   base_long <- base |>
     pivot_longer(starts_with("dummy_atendida_real_"),
                  names_to = "ano", values_to = "atendida") |>
     mutate(ano = as.numeric(gsub("dummy_atendida_real_", "", ano)))
