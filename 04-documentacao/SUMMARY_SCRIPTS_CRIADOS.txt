🔍 INTERPRETAÇÃO RÁPIDA:

No arquivo resultados_bateria_iv.csv procure por:

┌──────────────────────────────────────────────────────────────┐
│ COLUNA       │ O QUE É              │ IDEAL                  │
├──────────────────────────────────────────────────────────────┤
│ f_stat       │ Força do instrumento  │ > 10 (forte)          │
│ coef_ss      │ Efeito causal         │ Significativo + robusto│
│ p_value      │ Significância         │ < 0.05 (5%)           │
│ r2_ss        │ Qualidade do ajuste   │ Alto (quanto maior)    │
└──────────────────────────────────────────────────────────────┘

EXEMPLO:
  coef_ss = 0.15, p_value = 0.032, f_stat = 18.5
  → Aumentar 1 unidade de tratamento = +15% no outcome
  → Significativo a 3.2%
  → Instrumento forte (F >> 10)
